## Featured Projects

### TumorScan AI | Radiology Assistant

🔗 [View Repository](https://github.com/Maheen012/TumorScan-AI)

- Developed a deep learning-based brain tumor classification system using **EfficientNetB0 CNN** and MRI imaging data.  
- Created a **4 class classifier** capable of detecting Glioma, Meningioma, Pituitary tumors, and Normal MRI brain scans.  
- Achieved **97.22% test accuracy** with strong precision, recall, and F1-scores across all tumor classes.  
- Designed and deployed an interactive **Streamlit web application** for MRI upload, real-time prediction, and diagnostic report generation.  
- Utilized **TensorFlow, Keras, OpenCV, Scikit-learn, NumPy, and Streamlit** for end-to-end model development and deployment.

### MoodLens | AI-Powered Mental Wellness Tracker

🔗 [View Repository](https://github.com/Maheen012/MoodLens)

- Developed an AI-powered mental wellness tracker focused on mood monitoring, stress tracking, and reflective journaling.  
- Integrated the **Google Gemini API** to generate empathetic AI-driven reflections, coping suggestions, and emotional pattern insights.  
- Implemented **Speech-to-Text** and **Text-to-Speech** functionality using the **Web Speech API** and **AWS Polly** to improve accessibility.  
- Designed a responsive and privacy-focused interface using **React** and **Tailwind CSS** with local journal storage and no user accounts required.  
- Added crisis-awareness features that detect high-risk emotional language and provide mental health support resources for users in the US and Canada.  
- Developed the backend using **FastAPI** and automated setup scripts for Windows and Linux environments.
